地形

HEX をクリック・ドラッグでなぞります。「なだらか」は中心から 1 HEX 離れるごとに 1 段ずつ弱めます（山・谷の斜面）。[ ] キーで半径を変更。標高は「表示 → HEX 塗り → 標高」で色分けすると見やすくなります

矩形: ドラッグした 2 つの HEX を対角にした範囲を塗ります（森を作るときなど）。「範囲内の水域・山岳は残す」で範囲内の川・山はそのままにします。ブラシはなぞった HEX を必ず上塗りします（川を草原で塗って消すなど）。水域を塗ると標高 0 になり、建物は撤去、街道には橋が架かります

引く: HEX をドラッグでなぞると川になります（標高 0。一歩戻ると取り消し）。「両岸を削る」は川から 1 HEX 先を 1 段、2 HEX 先を 2 段までに下げ、高台を流れる川でも谷になります。街道が通る HEX には橋が架かります。

消す: なぞった水域を草原に戻します（標高は隣の陸の低い方にそろえ、橋は撤去）。「地形」のブラシで草原などを塗っても消せます

全地形クリア

全 HEX を選んだ地形にします（戦闘の範囲・初期配置地点は残ります）。「元に戻す」で戻せます

人工物

HEX をクリックして配置。同じ人工物をもう一度クリックで撤去（橋は向きを変更）。隣り合う砦・城は 1 つにつながります。「街道」は HEX をドラッグでなぞって引きます。「撤去」はクリックで人工物（無ければ街道）を、ドラッグでなぞった HEX の人工物と街道をまとめて撤去します

街道マップ

戦略マップの街道でつながる 2 都市（A–B）を 1 枚に描いたマップで、侵攻方向ごとの戦闘の範囲を決めます。範囲は防衛する都市の ID で引きます（A→B の侵攻なら B の範囲）。都市を選んで「範囲を配置」でマップをクリック・ドラッグすると、その HEX を中心に範囲が動きます（列・行は偶数に寄せます）。

「攻撃側の配置」「防衛側の配置」で、選んだ範囲の初期配置地点（戦闘でユニットを自由に置ける HEX）をクリック・ドラッグで塗ります。配置地点の HEX から始めると消します。範囲の外・水域には置けません。「範囲だけ表示」はゲームの戦闘で使う切り出し後の見た目です（その間は編集できません）。ファイル名は road-<小さい ID>-<大きい ID>.json にします

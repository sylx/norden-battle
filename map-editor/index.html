マップ

保存先はリポジトリ直下の assets/maps/ です（battle-editor からも読み込めます）。「保存」はファイル名欄の名前で書き込みます。JSON ファイルをドロップしても開けます

街道マップ

戦略マップの街道でつながる 2 都市（A–B）を 1 枚に描いたマップで、侵攻方向ごとの戦闘の範囲を決めます。範囲は防衛する都市の ID で引きます（A→B の侵攻なら B の範囲）。都市を選んで「範囲を配置」でマップをクリック・ドラッグすると、その HEX を中心に範囲が動きます（列・行は偶数に寄せます）。「範囲だけ表示」はゲームの戦闘で使う切り出し後の見た目です（その間は編集できません）。ファイル名は road-<小さい ID>-<大きい ID>.json にします

人工物の配置

HEX をクリックして配置。同じ人工物をもう一度クリックで撤去（橋は向きを変更）。隣り合う砦・城は 1 つにつながります。「森↔草原」は森を伐採して草原に、草原に植林して森にします。「街道」は HEX をドラッグでなぞって引き、「撤去」でなぞると消せます

ユニット

「配置」で HEX をクリックすると置けます。同じユニットをもう一度クリックで左右の向きを反転、「撤去」ツールで取り除けます

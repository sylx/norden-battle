# Norden Map Editor

HEX マップデータ (JSON) からプロシージャルな 3D 地形を生成し、HEX グリッドを重ねて表示・編集するツール。
three.js + TypeScript + Vite。地形生成・描画は [map-runtime](../map-runtime/) にあり、battle-editor と共有している。

```sh
npm install
npm run dev          # http://localhost:5173/
npm run gen:samples  # assets/maps/ のサンプルを再生成（同名のファイルは上書き）
npm run build
```

URL パラメータ: `?map=pointy-test.json`（assets/maps/ のファイルを開く）、`?seed=5`（ランダムマップ）

## マップの保存先

マップはリポジトリ直下の [assets/maps/](../assets/maps/) に置く。上部のバーの検索欄（名前・ファイル名で絞り込める）でマップを選び、
「読み込み」で開く（候補を閉じた状態で Enter でも読み込む）。「保存」（Ctrl+S）でファイル名欄の名前で書き込む
（開発サーバー経由。`npm run build` した静的版では保存できない）。保存していない編集があるときは、別のマップを開く前に確認する。
battle-editor は同じ場所から読み込む。ローカルの JSON を開く・ダウンロードすることもできる。
形式は [map-runtime の README](../map-runtime/README.md#マップ-json-version-1) を参照。

## 操作

- 左ドラッグ: カメラの移動（編集ツールを選んでいる間は編集）、右ドラッグ: カメラの移動、中ドラッグ: カメラの俯角（上へで水平寄り、下へで真上寄り）、ホイール: ズーム
- カーソルの右下に、その HEX の地形・標高（人工物・座標）を出す
- Esc: 選択ツールに戻る / Ctrl+Z: 元に戻す / Ctrl+Y・Ctrl+Shift+Z: やり直す / Ctrl+S: 保存 / [ ]: ブラシの半径
- 編集はすべて「元に戻す」で戻せる（マップを開き直すと履歴は消える）

### 地形

- **標高**: HEX をクリック・ドラッグでなぞって標高を変える。操作は「上げる」「下げる」「平らにする（なぞり始めた HEX の高さ）」「指定の高さにする」。
  半径を広げると周りの HEX にも効き、「裾野をなだらかに」で中心から 1 HEX ごとに 1 段ずつ弱める。
  プリセット: 山（3 段・半径 2・なだらか・山岳/丘陵に）、谷（2 段下げ・半径 1・なだらか）、台地（1 段・半径 1・縁は崖）、平らに。
  「水域は変えない」を外すと水域も持ち上げられる（持ち上げた水域は草原になる）
- **地形**: 選んだ地形で塗る。「矩形で範囲選択」はドラッグした 2 つの HEX を対角にした範囲（森を作るときなど）、「ブラシ」はなぞった所。
  水域を塗ると標高 0 になり、建物は撤去、街道には橋が架かる。矩形では「範囲内の水域・山岳は残す」で既存の川・山を残して塗れる（ブラシは常に上塗り）
- **川**: 「引く」で HEX をドラッグでなぞると川（標高 0）になる。「両岸を削る」で川から 1 HEX 先を 1 段、2 HEX 先を 2 段までに下げる（高台を流れる川が谷になる）。
  「消す」でなぞった水域を草原に戻す（標高は隣の陸の低い方にそろえ、橋は撤去）
- **全地形クリア**: 全 HEX を 1 つの地形にする。標高は一定か、ノイズによるランダム（最低・最高・起伏の細かさ・シード）。
  ランダムでは高い所を丘陵・山岳にできる。「ランダムに森を置く」で、選んだ地形のままの陸の HEX のうち指定の割合（ノイズでまとまった所）を森にする
  （丘陵・山岳にした所と水域は除く。シードは標高と共通）。人工物・街道も消すかを選べる（戦闘の範囲・初期配置地点は残る）

水面の高さはマップ全体で一定なので、水域は標高 0 にしておく（エディタの川・地形ツールはそうする）。

### 人工物

「人工物」のボタンを選んで HEX をクリックすると配置できる（同じものを再クリックで撤去、橋は向きを変更）。
城はドラッグでなぞって塗ることもでき、「郭の段」（1 = 外郭 〜 3 = 最も内側）を選んで置く。段の違う HEX の境にも城壁・塔が立ち、
二重・三重の城壁になる（内側ほど高く、郭ごとに門が 1 つ）。違う段の城をクリックすると段を変える。「郭の段を外周から自動で振る」で、
城の外に面した HEX を 1、その内側を 2、… と上限（二重・三重）まで振る。城の地面は石畳になる。「街道」ツールで HEX をドラッグでなぞって街道を引ける。「撤去」ツールはクリックで人工物（無ければ街道）を、ドラッグでなぞった HEX の人工物と街道をまとめて撤去する。

ユニットの配置はエディタでは扱わない（マップ JSON に入っているユニットは表示せず、保存時にそのまま残す）。

### 軽量表示

「表示」欄の「軽量表示」で、描画解像度を 1 倍まで・地形の頂点密度を下げ、木・影・羊皮紙風の加工を止める。編集中の描画や地形の作り直しが軽くなる。
保存されるマップは変わらない。設定はブラウザに覚えておく。

## 街道マップ

nordencult の戦略マップの街道でつながる 2 都市を 1 枚に描いたマップ（`road-<小さい ID>-<大きい ID>.json`、例 `road-P004-P012.json`）では、
「街道マップ」欄で両端の都市 ID と、防衛する都市ごとの戦闘の範囲（16×16）・初期配置地点を設定する。

- 都市 A・B を入れると、それぞれの範囲の行が出る。行を選ぶとその範囲の枠（橙）と初期配置地点を表示する
- 「範囲を配置」でマップをクリック・ドラッグすると、その HEX を中心に範囲が動く（flat は列、pointy は行を偶数に寄せ、マップに収める）
- 「攻撃側の配置」「防衛側の配置」で、選んだ範囲の初期配置地点（戦闘でユーザーがユニットを自由に置ける HEX）をクリック・ドラッグで塗る。
  配置地点の HEX からなぞり始めると消す。範囲の外と水域（橋の上は可）には置けない。地点は街道マップの座標で持ち、範囲を動かしても動かない
  （範囲の外に出た地点は行に「範囲外」と出て、戦闘では使われない）
- 「範囲だけ表示」で、ゲームの戦闘で使う切り出し後のマップを表示する（その間は編集できない。保存は元のマップ）

形式は [map-runtime の README](../map-runtime/README.md#街道マップと戦闘の範囲) を参照。

# Norden Battle Editor

戦闘画面の UI・演出を試し、演出のパラメータを調整するためのツール。three.js + React + TypeScript + Vite。

戦闘画面は [battle-runtime](../battle-runtime/) の `BattleScreen`（ゲーム本体と同じもの）で、ここではその上にエディタの道具
（ツールバー・マップ・部隊・CPU・速度・拠点施設・描画負荷・セリフ・状態・退却・捕縛）を重ねるだけ。マップの描画は map-editor と同じ [map-runtime](../map-runtime/) の `MapView` を使い、
地形生成などのパラメータは map-editor の初期値のまま。UI の部品は [norden-ui](https://github.com/sylx/norden-ui)（リポジトリの隣の `../../norden-ui`）。

ゲーム（nordencult）のデータ（騎士・勢力・セリフ・顔の画像。`../../src/`）を直接読むので、norden-battle は nordencult のサブモジュールとして置いておくこと。

```sh
npm install
npm run dev          # http://localhost:5175/
npm run build
```

URL パラメータ: `?map=pointy-test.json`（assets/maps/ のファイルを開く）

## マップ

ツールバーの「マップ」で開くウィンドウから、map-editor で保存したマップ（リポジトリ直下の [assets/maps/](../assets/maps/)）を「保存済み」で選んで読み込む。
map-editor で保存し直したら「一覧を更新」で反映される。ローカルの JSON を開く・ドロップすることもできる。
街道マップ（`battleAreas` のあるマップ）は「戦闘の範囲」で防衛する都市の範囲を選んで切り出す（既定は初期配置地点のある最初の範囲）。
切り出したマップは初期配置地点に部隊を置く配備から始まる。「最初から」で同じマップを読み込み直して配備からやり直せる。
battle-editor からマップは書き換えない。

## 部隊

ツールバーの「部隊」で、陣営（攻撃側・防衛側）ごとに、ゲームの勢力と騎士で編成を組む（[src/gameKnights.ts](src/gameKnights.ts)）。
勢力を選ぶとその勢力の騎士で組み直し（当主が先頭、あとは統率の高い順に 8 部隊）、先頭の騎士が軍団長になる。
部隊ごとに騎士・兵種・兵数・士気と軍団長を選び直せる。魔術師・上級魔術師には魔法（フレイムランスなど）を持たせられる
（サンダーフォールは必ず使える。ゲームでは魔導書の装備から渡す）。兵種は騎士の種別で率いられないもの（新しい兵種など）も選べる。
部隊の能力（統率・武力・知力）・名前・顔は騎士のもの（ゲームの `battleTroops.ts` と同じ）で、傭兵は捕縛されない。
ゲームの騎士にはまだ戦闘のスキルが無いので、スキルは表示確認用に行の順で仮に配る。

直した編成は「この編成で最初から」で反映する。反映した編成はブラウザに覚えておき、開き直しても同じ編成で始める
（覚えた編成に今のデータに無い騎士がいれば既定の編成に戻る。既定はヴァルハルト家が攻撃側、ノルディス家が防衛側）。
配備の無いマップ（ユニットを置いてあるマップ）では、防衛側の編成を赤軍、攻撃側の編成を青軍のユニットに上から順に割り当てる（兵種はマップのまま。部隊の道具の表もマップのユニットの兵種を「マップでは〜」と出し、魔術師系なら魔法の欄を出す）。
「編成を書き出す」で、いま道具に出ている編成を `rosters.json` に書き出す（対戦シミュレータの `--rosters` に渡す）。

## CPU・速度

ツールバーの「CPU・速度」で、陣営ごとに人が操作するか CPU（易しい・普通・難しい）に任せるかと、演出の速度（×0.5〜×3）を選ぶ。
すぐ反映し（戦闘の途中でも）、ブラウザに覚えておく。両方の陣営を CPU にすると最後まで勝手に戦う。
CPU の陣営は配備も自動配置で済ませる。CPU の番のターン表示には「早送り」（演出をさらに 3 倍に）と「スキップ」（番の残りを演出なしで進める）を出す。
決着のカットインは、人が操作する陣営をプレイヤーとして勝利・敗北を出す（両方とも人・両方とも CPU なら攻撃側）。
難易度はまだ手に効かない（M008 の段階 3 で入れる）。

## 対戦シミュレータ

描画なしで CPU（やランダムな打ち手）どうしを何度も戦わせ、勝率・決着の理由・ターン数・兵種ごとのダメージ・同じ所の行き来の回数を表に出す
（[sim/cli.ts](sim/cli.ts)。norden-battle の直下で `npm run sim -- …`。[sim/run.mjs](sim/run.mjs) が Vite のモジュールランナーで動かす）。
シードを固定すれば同じ結果になる。

```sh
npm run sim -- --runs 20                                  # 既定のマップ（戦闘の範囲のある最初のファイル）の最初の範囲で 20 戦
npm run sim -- --map road-P000-P013.json --area P013 --verbose   # 範囲を選び、1 戦ごとの結果と行き来も出す
npm run sim -- --map all --runs 4                         # すべてのマップのすべての範囲を 4 戦ずつ
npm run sim -- --attacker hard --defender random          # 打ち手（easy・normal・hard・random。既定は normal）
npm run sim -- --rosters rosters.json                     # 編成（部隊の道具で書き出したもの）
npm run sim -- --attacker-faction leonis --defender-faction carta  # 勢力の既定の編成
npm run sim -- --seed 100 --max-turns 40 --no-retreat     # シード・ターンの上限・退却先を渡さない
```

両軍は自動配置で置く。退却先は既定で両軍にダミーの拠点を 1 つずつ渡す（退却・強制退却が起きる）。拠点の施設はまだ渡せない。

## ダメージ計算

ツールバーの「ダメージ計算」で、部隊を組んで攻撃しなくても攻撃 1 回のダメージを確かめられる（[src/DamageTool.tsx](src/DamageTool.tsx)）。
計算は戦闘と同じ battle-runtime の `calcDamage`・`calcCounter`・`moraleChange` なので、[damage.ts](../battle-runtime/src/damage.ts) の値を直せばそのまま反映される。

- 攻撃側・防御側: 兵種・兵数・士気・統率・武力・知力（魔術師・上級魔術師は武力の代わりに知力）・地形（城・砦も）・包囲。騎士を選ぶと統率・武力・知力をその騎士の値にする
- 攻撃: 兵種の攻撃（魔術師・上級魔術師は全魔法）と当たり方（直撃・範囲の巻き添え・迎撃の自動攻撃）、隣接しているか（反撃）、一斉攻撃に加わる味方の数、標高差
- 防御側の迎撃の構え（近接の兵種）
- 結果: ダメージ（ランダムの真ん中と幅）・反撃・防御側の残り・両軍の士気の増減（幅と増減した後の値）・付く状態・計算と士気の増減の内訳・同じ攻撃を続けて倒すまでの回数・防御側の兵種ごとの比較

入力はすぐ反映し、ブラウザに覚えておく。

## セリフ

ツールバーの「セリフ」で、喋る場面で必ず喋らせたり、選択中のユニットに場面ごとのセリフを言わせたりできる。言ったセリフは下に記録される。

ゲームのセリフのデータ（`../../src/data/voiceLines.json`。norden-data のセリフエディタで書く）を読み、部隊を率いる騎士の口調・性格に合わせて喋る
（[src/gameVoices.ts](src/gameVoices.ts)）。ユニットごとに喋る騎士を選び直せる（吹き出しに騎士の顔は出さない）。
norden-data でセリフを保存すると、開いている battle-editor にもそのまま反映される。

## 拠点施設

ツールバーの「拠点施設」で、陣営ごとに要塞砲・ガンシップ（撃つ間隔）・バリスタ・魔導台を持たせる（すぐ反映する。ブラウザに覚えておく）。
要塞砲・ガンシップはその陣営の番の終わりに撃つ（要塞砲は拠点から撃つので、拠点のあるマップの防衛側に持たせる）。
バリスタ・魔導台は城の HEX にいるその陣営の弓兵・魔術師の射程を伸ばす。

## 状態

ツールバーの「状態」で、選択中か調べているユニットに状態（混乱・凍結）を付け外しし、攻撃をクールタイム中にできる（見え方の確認用。
状態はまだ効果が無い）。状態は情報札の右上の印と騎士のウィンドウに、クールタイムは行動メニューの灰色の項目と騎士のウィンドウに出る。

## 退却・捕縛

ツールバーの「退却・捕縛」で、軍ごとにダミーの退却先の拠点を渡すかどうかを切り替える（渡さない軍のユニットは退却を選べない。
既定は両軍とも渡す）。退却に失敗する確率と殲滅されて捕縛される確率の表と、退却・殲滅の結果（捕虜になったか）の記録も出す。

## 決着

どちらかの陣営の部隊がすべて殲滅・退却するか、攻撃側のユニットが防衛拠点（範囲を切り出したマップの `stronghold`。地面が金色）に入ると決着し、
攻撃側をプレイヤーとした勝利・敗北のカットイン（`battle-win`・`battle-lose`）の後に決着のウィンドウを出す。その「最初から」で同じマップを読み込み直す。

## 構成

```
src/
  main.tsx         入口
  EditorApp.tsx    BattleScreen にツールバーと道具のウィンドウ（マップ・部隊・拠点施設・描画負荷・セリフ・状態・退却・捕縛）を重ねる。JSON のドロップ
  gameKnights.ts   ゲームの騎士・勢力のデータと顔。陣営ごとの編成から、配備する部隊とマップのユニットの状態を作る
  gameVoices.ts    ゲームのセリフのデータ。ユニットに喋らせる騎士の割り当て
  style.css        ツールバーと道具のウィンドウ
```

戦闘のルール・戦闘画面の UI（地形・戦闘記録・行動メニュー）は [battle-runtime](../battle-runtime/) にある。

# Norden Battle Editor

戦闘画面の UI・演出を試し、演出のパラメータを調整するためのツール。three.js + React + TypeScript + Vite。

戦闘画面は [battle-runtime](../battle-runtime/) の `BattleScreen`（ゲーム本体と同じもの）で、ここではその上にエディタの道具
（ツールバー・マップ・部隊・描画負荷・セリフ・状態・退却・捕縛）を重ねるだけ。マップの描画は map-editor と同じ [map-runtime](../map-runtime/) の `MapView` を使い、
地形生成などのパラメータは map-editor の初期値のまま。UI の部品は [norden-ui](https://github.com/sylx/norden-ui)（リポジトリの隣の `../../norden-ui`）。

ゲーム（nordencult）のデータ（騎士・勢力・セリフ・顔の画像。`../../src/`）を直接読むので、norden-battle は nordencult のサブモジュールとして置いておくこと。

```sh
npm install
npm run dev          # http://localhost:5175/
npm run build
```

URL パラメータ: `?map=pointy-test.json`（assets/maps/ のファイルを開く）

## マップ

ツールバーの「マップ」で開くウィンドウから、map-editor で保存したマップ（リポジトリ直下の [assets/maps/](../assets/maps/)）を「保存済み」で選んで読み込む。
map-editor で保存し直したら「一覧を更新」で反映される。ローカルの JSON を開く・ドロップすることもできる。
街道マップ（`battleAreas` のあるマップ）は「戦闘の範囲」で防衛する都市の範囲を選んで切り出す（既定は初期配置地点のある最初の範囲）。
切り出したマップは初期配置地点に部隊を置く配備から始まる。「最初から」で同じマップを読み込み直して配備からやり直せる。
battle-editor からマップは書き換えない。

## 部隊

ツールバーの「部隊」で、陣営（攻撃側・防衛側）ごとに、ゲームの勢力と騎士で編成を組む（[src/gameKnights.ts](src/gameKnights.ts)）。
勢力を選ぶとその勢力の騎士で組み直し（当主が先頭、あとは統率の高い順に 8 部隊）、先頭の騎士が軍団長になる。
部隊ごとに騎士・兵種・兵数・士気と軍団長を選び直せる。魔術師・上級魔術師には魔法（フレイムランスなど）を持たせられる
（サンダーフォールは必ず使える。ゲームでは魔導書の装備から渡す）。兵種は騎士の種別で率いられないもの（新しい兵種など）も選べる。
部隊の能力（統率・武力・知力）・名前・顔は騎士のもの（ゲームの `battleTroops.ts` と同じ）で、傭兵は捕縛されない。
ゲームの騎士にはまだ戦闘のスキルが無いので、スキルは表示確認用に行の順で仮に配る。

直した編成は「この編成で最初から」で反映する。反映した編成はブラウザに覚えておき、開き直しても同じ編成で始める
（覚えた編成に今のデータに無い騎士がいれば既定の編成に戻る。既定はヴァルハルト家が攻撃側、ノルディス家が防衛側）。
配備の無いマップ（ユニットを置いてあるマップ）では、防衛側の編成を赤軍、攻撃側の編成を青軍のユニットに上から順に割り当てる（兵種はマップのまま）。

## セリフ

ツールバーの「セリフ」で、喋る場面で必ず喋らせたり、選択中のユニットに場面ごとのセリフを言わせたりできる。言ったセリフは下に記録される。

ゲームのセリフのデータ（`../../src/data/voiceLines.json`。norden-data のセリフエディタで書く）を読み、部隊を率いる騎士の口調・性格に合わせて喋る
（[src/gameVoices.ts](src/gameVoices.ts)）。ユニットごとに喋る騎士を選び直せる（吹き出しに騎士の顔は出さない）。
norden-data でセリフを保存すると、開いている battle-editor にもそのまま反映される。

## 状態

ツールバーの「状態」で、選択中か調べているユニットに状態（混乱・凍結・感電）を付け外しし、攻撃をクールタイム中にできる（見え方の確認用。
状態はまだ効果が無い）。状態は情報札の右上の印と騎士のウィンドウに、クールタイムは行動メニューの灰色の項目と騎士のウィンドウに出る。

## 退却・捕縛

ツールバーの「退却・捕縛」で、軍ごとにダミーの退却先の拠点を渡すかどうかを切り替える（渡さない軍のユニットは退却を選べない。
既定は両軍とも渡す）。退却に失敗する確率と殲滅されて捕縛される確率の表と、退却・殲滅の結果（捕虜になったか）の記録も出す。

## 決着

どちらかの陣営の部隊がすべて殲滅・退却するか、攻撃側のユニットが防衛拠点（範囲を切り出したマップの `stronghold`。地面が金色）に入ると決着し、
攻撃側をプレイヤーとした勝利・敗北のカットイン（`battle-win`・`battle-lose`）の後に決着のウィンドウを出す。その「最初から」で同じマップを読み込み直す。

## 構成

```
src/
  main.tsx         入口
  EditorApp.tsx    BattleScreen にツールバーと道具のウィンドウ（マップ・部隊・描画負荷・セリフ・状態・退却・捕縛）を重ねる。JSON のドロップ
  gameKnights.ts   ゲームの騎士・勢力のデータと顔。陣営ごとの編成から、配備する部隊とマップのユニットの状態を作る
  gameVoices.ts    ゲームのセリフのデータ。ユニットに喋らせる騎士の割り当て
  style.css        ツールバーと道具のウィンドウ
```

戦闘のルール・戦闘画面の UI（地形・戦闘記録・行動メニュー）は [battle-runtime](../battle-runtime/) にある。

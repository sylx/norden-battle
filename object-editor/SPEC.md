# object-editor 仕様

## 背景
- map-editor の人工物（村・城・砦・橋）は `render/structures/` で box / cone / roof をコードで組み、模様をシェーダで描いている。そのため「作り物っぽさ」が残り、バリエーションも少ない。
- ユーザーは Blender を使えない。
- 画風は **ミニチュア／ジオラマ風**。

## 方針（2026-09-30 改訂）: ユニットは 2D 画像にする
ユニットを 3D で描くのはやめた。代わりに **マップのカメラの角度を固定し、ユニットは 2D 画像（スプライト）で描く**。表示は map-editor に実装した（下の「ユニットの表示（2D）」）。

これにより object-editor の役割は、**建物の部品や近景用のモデルの取り込み口** に絞られる。兵士の生成・アニメーション・部隊のインスタンス描画（下の B〜D）は中止し、試作したコード（`asset-runtime/src/three/soldier/`・`crowd/`・`src/formation.ts`、object-editor の `src/lab/`）は参考として残してある。

## ユニットの表示（2D、map-editor）
- **カメラ**（`map-editor/src/render/scene.ts`）: 回転させない。北向き、俯角は既定 50°（`DEFAULT_CAMERA_PITCH`。lil-gui の「カメラ → 俯角」で調整できる）。操作は移動とズームだけ。
- **画像**（`map-editor/src/render/unitArt.ts`）:
  - 兵種ごとに 1 枚。`map-editor/src/core/units.ts` の `UNIT_DEFS[type].image` に `public/` からの相対パスを書く。未指定なら Canvas で描いたプレースホルダーを使う（今は歩兵・弓兵・騎兵・魔術師の 4 種すべてプレースホルダー）。
  - 描き方の約束: **カメラの俯角から見下ろした姿を右向きで**描く。**下端中央が足元**。余白は付けない（画像の縦横比がそのままスプライトの縦横比になる）。左向きは反転して表示する。
  - 軍の色は画像ではなく足元の円で示すので、画像は軍で共通にできる。
- **描画**（`map-editor/src/render/units.ts`）:
  - HEX の中心にカメラ正対のスプライトを立てる。高さは hexSize の 0.95 倍。
  - 足元に軍の色の円を地面に沿わせて敷く。
  - スプライトも円も深度テストをせず、地形・木・建物より手前に描く（森や山の陰でもユニットを見失わないため）。ユニット同士は奥から順に描く。
  - クリック判定は画像の不透明な部分だけで取る。
- **データ**: マップ JSON に `units`（省略可）を追加した。`{ col, row, type, team, facing? }` で、1 HEX に 1 部隊。
- **これから**: 本番の画像（兵種ごと。必要なら人数の減り方に応じた差分）、HP や人数の表示、移動・攻撃の演出（2D のまま動かす）。

## 以前の方針（2026-09-29、中止）
当初は「外部素材を集めて整えて組む」方針だった。しかし、部隊で数百体を描くには素材もローポリにせざるを得ず、それならコードで生成しても見劣りしないと判断した。試作（`asset-runtime/src/three/soldier/`）で、戦闘カメラの距離なら十分使えることを確かめた。

| 対象 | 形 | 動き |
|---|---|---|
| **ユニット** | **プロシージャル生成**。Mixamo 骨格の各骨にコードで作ったパーツを固定する | **Mixamo** のモーションを取り込んでそのまま使う |
| **建物** | 配置は今の手続き生成のまま（地形に沿う・道を避ける・城壁がつながる）。形をコードで作り込むか、取り込んだ部品に差し替えるかは未決 | — |
| **指揮官などの近景用** | 必要なら取り込んだキャラ（Mixamo のキャラなど）を使う | Mixamo |

ディテールは素材ではなく、パーツの設計（シルエット・プロポーション・配色）で出す。プロシージャル感を消すのに必要なのはポリ数ではなく、この設計の手間である。

## 3D ユニットの仕組み（中止。試作コードの説明として残す）
- **骨格**: Mixamo 標準の骨格（骨の名前は `mixamorigHips` の形）。取り込んだキャラかモーションの基準姿勢（T ポーズ）から骨だけを取り出して雛形にする（`createSkeletonTemplate`）。
- **パーツ**: 胴・手足・頭・兜・鎧・武器・盾をコードで作り、それぞれ 1 本の骨に重み 1 で固定する。肌の変形がないので形が破綻しない。
  - 寸法は骨格から測る（身長 170 に対する単位 u。Mixamo なら 1u ≒ 1cm）。
  - 基準の向き: 体の正面は +Z、左は +X、T ポーズで手のひらは下。武器の柄と盾の向きはこれを前提に決める。
- **まとめ方**: 全パーツを頂点カラー＋フラットシェーディングの 1 つの SkinnedMesh にまとめる。1 体は約 1,000 三角形、1 ドローコール。
- **大きさ**: 身長 0.35（hexSize = 1）。現実の縮尺より見た目を優先し、1 HEX に 1 部隊（十数体）が並んで読める大きさにする（等身大の約 9 倍。建物より大きくなるので、建物は作り直すときに合わせる）。頭は大きめ（既定は 1.3 倍）。隊形の間隔は身長の 1.2 倍（横）・1.35 倍（縦）。
- **動き**: Mixamo のクリップをそのまま再生する。骨の名前がそろっているので、どのモーションもどの兵士にも当たる。
- **パラメータ**（`SoldierParams`）: 兜・鎧・武器・盾・チーム色・頭の大きさ・太さ・個体差のシード。個体差のシードで肌・髪・ズボンの色やひげが変わる。

## データモデル（`assets/catalog/`）
| 種類 | 状態 | 内容 |
|---|---|---|
| **Source** | 実装済み | 取り込んだ元ファイル。出典・ライセンス・正規化の変換（rotation / pivot / scale）・統計 |
| **Prefab**（建物） | 未決 | 建物を部品の差し替えにする場合だけ作る。部品の配置、バリアント規則、フットプリント、接続ソケット |
| ~~AnimClip / UnitType / SquadLayout~~ | 中止 | 3D ユニット用に予定していたもの |

ID で相互に参照する。ユニットの配置は map-editor のマップ JSON の `units` に持つ（兵種の定義は今は map-editor の `UNIT_DEFS`）。

## 機能一覧

### A. 取り込み・正規化（実装済み）
- GLB / glTF / FBX / OBJ をドロップして取り込む。テクスチャ・.bin・.mtl は一緒にドロップする。ブラウザで GLB に変換する。
- 自動で補正する: 骨の名前の表記ゆれ（`mixamorig:` `mixamorig1:` など）、Mixamo 骨格かどうかの判定、カテゴリごとの目安の高さへの拡大縮小、原点を足元の中心に置く。
- 手で調整する: 90° 単位の回転、原点、高さ（プリセットあり）。
- 出典・ライセンスの入力を必須にする。保存のたびに `assets/CREDITS.md` を作り直す。
- ポリ数・テクスチャの大きさが目安を超えると警告する。

### B〜D は中止（2026-09-30）
3D ユニットをやめたため。試作済みの内容は参考として残す。

### B. 兵士の試作場（試作済み、中止）
- 実装済み:
  - 装備・チーム色・体格・個体差を切り替えられる。
  - 1 体表示と部隊（12 体）表示を切り替えられる。
  - 取り込んだキャラを横に並べて比較できる。
  - 戦闘カメラの距離から見られる。
- これから:
  - パーツの作り込み: 兜の飾り、袖や裾の段、小物、盾の紋章。
  - 兵種（歩兵・槍兵・弓兵・騎士…）のプリセットを UnitType として保存する。
  - 武器の持ち方をクリップごとに補正する（柄の向き・握る位置）。

### C. アニメーション編集（未着手、中止）
- クリップの編集: トリム、ループ点、速度、その場化（ルートモーションを捨てる／使う）、左右反転。
- **レイヤーの合成**: 上半身マスクで「歩き（下半身）＋攻撃（上半身）」を作り、新しいクリップとしてベイクする。
- 遷移: ステート間のクロスフェード時間。
- イベント: 攻撃が当たる・矢を放つ・倒れきった、などのフレームに印を付ける。戦闘デモの演出の同期に使う。

### D. 部隊の描画（試作済み、中止）
- **ベイク**（`asset-runtime/src/three/crowd/bake.ts`）: 骨格 × クリップの骨の姿勢を 30fps でフロートテクスチャに焼く。1 行 = 1 フレーム、1 本の骨 = 横 4 テクセル（スキニング行列の 4 列）。death / die などの名前のクリップはループせず、最後の姿勢で止まる。
- **描画**（`crowd.ts` の `Crowd`）:
  - 兵種 × 見た目の種類（バリアント）ごとに InstancedMesh を 1 つ持つ。
  - 頂点シェーダで自分の骨の行列を前後 2 フレーム読んで補間する。どの頂点も 1 本の骨にしか付いていないので、読む行列は 1 本分で済む。
  - インスタンスごとに、クリップ（開始行・フレーム数）・開始時刻・速さ・チーム色を持つ。
  - チーム色は teamShade 属性の付いた頂点だけをシェーダで塗り替える。同じジオメトリを全チームで使える。
  - 影は customDepthMaterial に同じスキニングを入れて落とす。
  - ドローコールは「兵種 × 見た目の種類」に影の分を足した数で、兵の数に依存しない。
- **隊形**（`asset-runtime/src/formation.ts`）: 横隊。1 列は最大 4 人（13 人以上なら 5 人）で、最後の列は中央に寄せる。位置と向きを少し揺らす。
- **試作場の「大軍」モード**:
  - 両軍の部隊を HEX 盤面に並べ、兵の数・三角形・ドローコール・FPS を表示する。
  - インスタンス描画と、1 体ずつの SkinnedMesh を切り替えて比べられる。
- これから:
  - クリップの切り替えのクロスフェード（今は瞬時に切り替わる）
  - 地形の高さに合わせる（map-editor の Heightmap）
  - HP に応じて人数を減らす
  - 近景では SkinnedMesh に切り替える

### E. 建物（方針未決）

## リスク・未決事項
- **2D 画像と 3D 地形のなじみ**: スプライトは光と影を受けない。地形の光の向き（北西の太陽）に合わせて画像に陰影を描き込む必要がある。
- **俯角を変えると画像を描き直すことになる**: 本番の画像を作り始める前に俯角を決める。
- **ユニットが常に手前に描かれる**: 山や城壁の向こうのユニットも隠れない。遊びやすさ優先でこうしているが、見た目が不自然なら後で見直す。
- **ライセンス**: Mixamo の素材も有料アセットも、素材そのものは再配布できない。`assets/sources` を公開リポジトリに置くかどうかを決める必要がある（今は取り込んだ素材をコミットしていない）。
